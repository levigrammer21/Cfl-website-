FIREBASE
firestore.rules, storage.rules, firestore.indexes.json and firebase.json are
visible in this folder. The source files are prefixed with source-- so the
prebuilt website files are easy to identify.

Run python3 prepare-firebase.py to create a separate CFL-Firebase-Project
folder in your current working directory. Open that generated project and
follow README.md, starting with the Firebase activation section. The script
recreates the directory layout required by the Firebase CLI. If the Firebase
project already has rules for another app, merge CFL rules as documented.
